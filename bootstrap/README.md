## 代码风格要求

1. 尽量使用支持的高级语法，写出简洁优雅的实现，尽量避免面条、丑陋代码
2. 避免函数签名太长的封装，可以考虑使用高级的数据结构来传递
3. 每行宽度最多120字符；如果改写需要底层新基础语法支持，则从底层(ocaml)开始支持
  1. 如果改写让代码变得很丑，可以接受少量的超长代码
  2. 超长结构体可以写成多行的
5. 标准库的封装尽量类似python一些，让使用者使用方便简单
6. C函数的调用名称必须以 `__c_` 为前缀，如果有复用价值和必要，封装到标准库更规范
7. 常量int序号分配要连续不留空洞，接受按合理顺序重新分配序号，程序本身逻辑应该跟这些具体值无关
8. 常量优于魔法数字
