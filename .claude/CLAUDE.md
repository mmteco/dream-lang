9. 尽量放到标准库实现，仅在c层面实现必要的代码

11. 特殊文件夹
   1. examples 示例文件夹，用于给用户展示语言用法
   3. docs markdown文档
   2. test 测试
      1. 尽量只保存大而全的覆盖测试
      2. 避免太多文件
      3. 如果是已提交到git的就不要删了
      4. 如果 examples 里有，这里就不要重复

   1. 以后都从这里加载项目知识
   2. 生成的时候不要重复，可以用文件名序号排序历史，每次记录变更，如 250101-2103-xxx.md

    2. 使用方法: DEBUG=true dream build file.dm
    3. 输出包括运算符重载查找、参数类型匹配等信息
14. 每次任务结束之后
