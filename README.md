# Dream 编程语言

Dream 是一门语法类似Python，包含丰富的类型，支持模式匹配的现代编译型语言。

## 特性

- **Python 风格语法** - 缩进敏感，简洁易读
- **静态类型系统** - Hindley-Milner 类型推导
- **LLVM 后端** - 编译为高性能机器码
